# อภิธานศัพท์ ไทย–อังกฤษ

| ไทย | English | ความหมายสั้น |
|---|---|---|
| ค่าการสะท้อนกลับ | reflectivity, Z (dBZ) | กำลังสะท้อนจากอนุภาคในปริมาตรสุ่มตัวอย่าง ∝ ΣD⁶ |
| ค่าสะท้อนต่างขั้ว | differential reflectivity, ZDR | 10log(Zh/Zv) บอกความแบนของเม็ดฝน |
| สหสัมพันธ์ขั้วร่วม | copolar correlation coefficient, ρhv | ความคล้ายของสัญญาณ H และ V |
| เฟสต่างขั้ว | differential phase, ΦDP | ความต่างเฟส H–V สะสมตามระยะ |
| อัตราเปลี่ยนเฟสต่างขั้วจำเพาะ | specific differential phase, KDP | ½ dΦDP/dr |
| การลดทอนจำเพาะ | specific attenuation, A | dB/km ที่สูญเสียในฝน |
| การบังลำคลื่น | beam blockage (PBB, CBB) | สัดส่วนลำคลื่นที่ถูกภูมิประเทศบัง |
| ดัชนีคุณภาพเรดาร์ | radar quality index, RQI | คะแนน 0–1 ของความน่าเชื่อถือ |
| การสแกนแบบผสม | hybrid scan | เลือกมุมยกต่ำสุดที่ใช้ได้ในแต่ละ bin |
| ชั้นหลอมเหลว | melting layer / bright band | ชั้นที่หิมะละลายเป็นฝน |
| โปรไฟล์แนวดิ่งของค่าสะท้อน | vertical profile of reflectivity, VPR | Z ตามความสูง |
| การกระจายขนาดเม็ดฝน | drop size distribution, DSD | N(D) |
| การโมเสค | mosaicking / compositing | รวมเรดาร์หลายตัวเป็นแผนที่เดียว |
| การแก้การเคลื่อนที่ | advection correction | แทรกค่าระหว่างสแกนตามการเคลื่อนที่ของฝน |
| ความเอนเอียงค่าเดียวทั้งพื้นที่ | mean-field bias, MFB | ΣG/ΣR |
| ความเอนเอียงเชิงพื้นที่ | spatial (local) bias | ค่าแก้ที่แปรผันตามตำแหน่ง |
| การตรวจสอบไขว้แบบเว้นหนึ่ง | leave-one-out cross-validation | ประเมินโดยไม่ใช้จุดนั้นสร้างค่าแก้ |
| สิ่งรบกวนจากพื้นดิน | ground clutter | สัญญาณจากภูเขา อาคาร ต้นไม้ |
| การหักเหผิดปกติ | anomalous propagation, AP | ลำคลื่นโค้งลงกระทบพื้น |
