## การดูแล repository
- แก้เนื้อหา notebook ที่ `scripts/nbsrc/nbXX.py` แล้วรัน `cd scripts/nbsrc && python nbXX.py && mv notebooks/*.ipynb ../../notebooks/`
- เก็บ notebook **โดยไม่มีผลลัพธ์** (ผลลัพธ์ของเซลล์เฉลยจะเผยคำตอบ)
- `python scripts/strip_solutions.py` → `notebooks_no_solutions/` สำหรับใช้สอบ (ไม่ commit)
- ป้องกัน branch `main`: Settings ▸ Branches ▸ Add rule (Require pull request, ไม่อนุญาต force push)
- workflow `close-student-prs.yml` ปิด PR จาก fork อัตโนมัติ และ `smoke-test.yml` รัน notebook ทุกครั้งที่แก้ (หรือกดรันเองที่แท็บ Actions)
- ข้อมูลใหม่: `python scripts/build_teaching_packages.py --radar-dirs ... --srtm ...` → อัปโหลด zip ไปที่ Release ใหม่ แล้วแก้ `config/data_sources.yaml`
