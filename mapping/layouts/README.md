# แม่แบบหน้ากระดาษ (journal layouts)

| แบบ | ความกว้าง | ใช้กับ | เรียกใช้ |
|---|---|---|---|
| 1 คอลัมน์ | 90 มม. | กราฟเดี่ยว, แผนที่เล็ก | `pl.subplots(width="single", height_mm=…)` |
| 1.5 คอลัมน์ | 140 มม. | แผนที่เดี่ยว + colorbar | `pl.subplots(width="one_half", …)` |
| 2 คอลัมน์ | 190 มม. | หลายแผง (2×2, 1×3) | `pl.subplots(width="double", …)` |

องค์ประกอบแผนที่ (`radteach.mapping.basemap`): กริดพิกัด °E/°N · มาตราส่วน (กม.) · ลูกศรทิศเหนือ · ขอบลุ่มน้ำ ·
ตำแหน่งเรดาร์และวงรัศมี · แผนที่บอกตำแหน่ง (`inset_thailand`) · หมายเหตุแหล่งข้อมูล (`source_note`)
อัตราส่วนแกน = 1/cos(ละติจูดกลาง) เพื่อให้ระยะทางแนวตั้ง/แนวนอนถูกต้อง
บันทึกด้วย `pl.save(fig, "ชื่อ")` → `outputs/figures/ชื่อ.png` (600 dpi) และ `.pdf` (ฝังฟอนต์)
